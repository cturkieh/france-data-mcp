Installation

2 manières

URL distante

claude.ai, Claude Code, Cursor — rien à installer.

url "https://france-data-mcp.vercel.app/mcp"

Aucune DB locale à provisionner · override FRANCE_DATA_MCP_URL

{
  "mcpServers": {

      "args": ["-y", "france-data-mcp"]

  }
