4 Ce que ça débloque

La Route A (couche d'activités dérivée de RPPS) est prouvée. Le plan d'implémentation Phase 2 peut être écrit sur des paramètres mesurés :

  • Couche dérivée finess_hosted_activities (matview num_finess → activités[]), recalculée au cron RPPS.
  • v1 : biologie + imagerie (signal propre, N=3, GO franc).
  • v1.1 : pharmacie, avec le gate de catégorie.
  • Exposition via une option des tools famille ; le champ perimetre (Phase 1) bascule sa note quand la couche est active.
  • Tout site ajouté reste distinguable (source: 'activite_hebergee') — le MCP juxtapose, ne fond pas.
