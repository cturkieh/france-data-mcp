ALTER TABLE finess ADD siret CHAR(14), cle_ban TEXT, score_ban REAL, ADD geom_source TEXT CHECK (geom_source IN ('ans','previous_ingest','ban_address')), ADD CONSTRAINT finess_geom_source_iff_geom CHECK ((geom IS NULL) = (geom_source IS NULL)); UPDATE finess SET siret/cle_ban/score_ban/geom_source FROM raw -- one-shot, ~105 K lignes (index finess_siret_idx prévu puis RETIRÉ en revue : 0 consommateur, 0 scan) ingest_create_finess_staging() → recréée en superset strict (4 colonnes + index + contrainte) RPC d'ingestion (repli, pose BAN, diff) → écrivent/lisent la colonne, plus jsonb dans raw RPC de lecture ×3 → DROP + recréation avec siret, geom_source dans RETURNS TABLE

3Lot 2 — workflow_call de drain BAN + fermeture automatique des issues

Trois fichiers de 121-132 lignes, six valeurs varient plus un bloc FINESS (exit 2 = canari avec backlog restant). Aucun workflow_call dans le repo ; une composite ne peut référencer ni job.* ni secrets.* (prouvé run #33960886473) — argument pour un workflow_call, qui accepte secrets: inherit.

.github/workflows/ban-backfill.yml (on: workflow_call) inputs : source · source-label · issue-labels · failure-modes · killed-hint · max · tolerate-canary-backlog secrets: inherit · permissions: contents read, issues write steps : checkout (premier) → preflight secrets → pnpm/node → drain → Close pending-geocode issue (nouveau) → Alert on failure or cancelled run ban-backfill-{rpps,ameli,finess}.yml (~30 lignes) on: workflow_run [cron surveillé] + workflow_dispatch(max) · concurrency · garde conclusion == success permissions (redéclaration exigée) · jobs.backfill.uses: ./.github/workflows/ban-backfill.yml · with: 6 valeurs
Fermeture automatiqueDrain terminé en exit 0 (file vidée, pas un canari) → l'issue ouverte labellisée pending-geocode,<source> est fermée avec « ✅ File vidée par le drain du <date> : N traitées, M acceptées ». upsert-ops-issue gagne action: open|close (émetteur unique préservé) ; ban-backfill.mjs écrit processed / accepted / remaining en GITHUB_OUTPUT. Best-effort : échec = log LOUD, jamais un run rouge.

workflows-alerting.test.ts

Partition par parse YAML : réutilisable, appelants, workflows à steps. Le réutilisable porte checkout premier + alerte failure() || cancelled() + issues: write ; chaque appelant : permissions.issues = write, uses vers le réutilisable, with.source cohérent avec le nom du fichier, secrets: inherit ; compte explicite 7 + 1 ; chaque source de notify-pending-geocode a un drain qui ferme.
